# Do Generic Symbolic Features Add Anything?

Generated by `guitar/jsymbolic_comparison.py`. Tuned Random Forest, 5 folds, 
identical splits, hyperparameters selected on inner-CV balanced accuracy.


The question: the thesis hand-crafted every descriptor. Would an off-the-shelf 
symbolic feature library have done the job? jSymbolic features are computed from 
pitch, duration and voice structure and cannot encode fret or string choice, so 
this measures what the guitar-specific representation actually buys.


> **Coverage caveat.** music21 failed to parse 11 of 640 pieces, and the failures are *not* uniform over difficulty: their mean class is 4.64 against the corpus mean of 2.81. All three feature sets below are evaluated on the same 629 surviving pieces, so the A/B/C comparison is internally valid -- but set B's numbers here are **not** comparable to the thesis's 640-piece headline and must not be quoted as such.


- Pieces: 629
- jSymbolic features after screening: 272
- Provenance features dropped: 7
  (`js_AcousticGuitarFraction`, `js_ElectricGuitarFraction`, `js_ElectricInstrumentFraction`, `js_NumberOfPitchedInstruments`, `js_StringEnsembleFraction`, `js_ViolinFraction`, `js_WoodwindsFraction`)
- Guitar descriptors: 25

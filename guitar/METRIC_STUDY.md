### Caveat: Kendall tau-c must not be used for model comparison here

RubricNet emits **7** distinct classes on this fold set; the Random Forest emits 
**8**. RubricNet never predicts class 7 at all. Since tau-c is proportional to 
$m/(m-1)$ with $m$ the smaller of the distinct true and predicted class counts, that 
difference multiplies RubricNet's tau-c by roughly 1.021 relative to the forest -- 
**inflating the score of the model that is worse on the rarest class, precisely 
because it declines to predict it.**


| | scipy tau-c | rescaled to common $m=8$ | tau-b |
|---|---:|---:|---:|
| RubricNet | 0.6309 | 0.6180 | 0.6322 |
| Random Forest | 0.6039 | 0.6039 | 0.6242 |

Roughly half the apparent tau-c gap is normalisation, not model quality. The 
P(RubricNet > RF) figure for tau-c in the table above is therefore **not** 
evidence of superiority and should not be quoted. Use tau-b, which does not 
depend on $m$, or macro-MAE, which penalises the class-7 failure directly.
